# Tour Horizon — Sélecteur 3D de bureaux à louer

Démo d'un site immobilier interactif : l'immeuble en 3D, le choix d'un étage, puis d'un bureau avec ses détails (surface, loyer, statut, équipements) et une demande de visite.

**Démo en ligne :** https://dieudonne19.github.io/tour-horizon-3d/

- Three.js (via CDN), une seule page HTML, sans build
- Responsive (mobile et ordinateur)
- Données de l'immeuble modifiables en haut du script (section « 1. DONNÉES »)

Immeuble, prix et disponibilités fictifs.

Conception : [Dieudonné Andrianjato](https://dieudonneandrianjato.vercel.app/)
